01 / ABOUT

💡 它是什么

“周报整理员”（Weekly Report Compiler）是基于 Hermes Agent 与飞书 Bot 构建的 AI 数字员工。它模拟行政助理的工作方式，自动收集一周内的工作信息，按项目归类，生成标准周报并写入飞书文档。

它减少每周翻查聊天记录、检查表格和整理格式的重复劳动，帮助用户更快审阅周报；工作判断和最终确认仍由用户完成。

03 / TOOLKIT

🧰 使用的工具与输入来源

工具

  • ZCode：负责 Agent 的开发与调试。
  • Hermes Agent：管理用户配置、定时任务和执行流程。
  • 飞书 CLI + Bot：连接飞书，读取或写入文档和表格，并交付结果。
  • DeepSeek：理解任务并生成周报内容。

输入来源

  • 飞书群聊记录：各项目群日常工作更新。
  • 飞书多维表格：项目跟踪和子任务状态。
  • 飞书妙记 / 腾讯会议：会议纪要或转写文本。
  • Bot 消息：用户主动发送的工作片段。
04 / WORKFLOW

⚙️ 处理流程

必须
从群聊提取含“已完成”“已交付”等状态词的工作消息。
必须
读取本周更新过的多维表格行。
建议
从会议纪要提取“结论”“待办事项”和“负责人”。
可选
汇总用户每天发给 Bot 的工作片段。
必须
按项目或主题整理，区分已交付成果与后续计划。
必须
以多维表格作为状态核对依据，检查数据一致性。
必须
生成包含成果、计划、问题和附件来源的结构化周报。
必须
创建飞书文档，检查访问权限并提供文档链接。
05 / REPORT

📤 周报文档结构

📊

本周成果

按项目列出已完成事项及当前状态。

📅

下周计划

从未完成事项和已确认计划中整理后续工作。

⚠️

遇到的问题

记录阻碍、风险及已有的应对方案。

📎

附件与来源

添加会议链接、项目表格链接及相关资料。

06 / GUARDRAILS

✅ 能力与使用边界

可以做

  • 自动提取飞书群聊中的工作记录。
  • 读取项目多维表格并整理状态。
  • 总结会议纪要和待办事项。
  • 按项目或主题分类内容。
  • 生成标准格式的飞书周报文档。

不能做

  • 不能凭空编造不存在的工作进展。
  • 不能修改多维表格中的原始数据。
  • 未经确认，不应向第三方发送未审阅的草稿。
  • 不能替代管理者的判断。
  • 数据严重缺失时，必须由用户确认。
07 / GET STARTED

🚀 如何触发

在飞书中找到 Weekly Report Compiler Bot 并发送：
生成周报

也可以配置为每周五 17:00 自动运行。
08 / NOTES

⚠️ 使用注意

  • 自动生成的内容须经人工检查和确认后再使用。
  • 需预先配置多维表格中的项目跟踪字段。
  • 目前尚未接入微信内容，计划在后续版本支持。
  • 不用于敏感人事决策。
  • 周报只整理已有记录。数据缺失、状态冲突或来源不明时，应明确标注并交由用户确认，不推断或补造进度。
